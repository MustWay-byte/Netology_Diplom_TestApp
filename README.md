# Тестовое приложение (DevOps Diplom)

Этот репозиторий содержит исходный код тестового приложения, разработанного в рамках дипломной работы курса **«DevOps инженер»** от Нетологии. 

Приложение эмулирует основной продукт компании и предназначено для отработки практик контейнеризации, сборки Docker-образов и последующего автоматизированного развёртывания в Kubernetes-кластер (Yandex Cloud).

## Структура проекта

```text
.
├── app/
│   ├── Dockerfile      # Инструкции для сборки минималистичного Docker-образа
│   ├── index.html      # Статическая HTML-страница (эмуляция фронтенда)
│   └── nginx.conf      # Кастомная конфигурация веб-сервера Nginx
└── README.md           # Этот файл
```
